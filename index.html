Start the server to view the website

This page is rendered from the content you manage in the admin panel, so it has to be served by the local Node server rather than opened as a file.

  1. Open Terminal
  2. Move into the project folder:
    cd "Varanasi_Guest_House_Final 2"
  3. Start the site:
    node server.js
  4. Then open http://localhost:3000/

On a Mac you can also just double-click START.command in this folder — it starts the server and opens the browser for you.
