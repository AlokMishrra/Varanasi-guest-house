# Varanasi Guest House Website

Open `index.html` in a browser.

Included:
- Responsive homepage matching the supplied design direction
- Sticky navigation and smooth section scrolling
- Hero booking widget
- Room cards and room-specific booking
- Gallery lightbox
- Booking modal
- WhatsApp booking request flow
- Contact/call buttons
- Google Maps direction button
- Mobile navigation
- Responsive tablet/mobile layout

IMPORTANT BEFORE CLIENT LAUNCH:
1. Replace WHATSAPP in index.html with the client's actual WhatsApp number.
2. Replace the demo phone number.
3. Replace the demo room prices/details with verified client data.
4. Replace image URLs with the client's real property photographs.
5. Replace the Google Maps search button with the exact property Maps URL/embed.
6. For real availability, room inventory, payments, cancellation rules and automatic confirmations, connect the booking form to a backend/PMS/payment gateway. The included WhatsApp flow is a working enquiry/request flow, not a real-time inventory engine.
