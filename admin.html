The admin panel needs the server running

You opened admin.html straight from the folder, so its stylesheet and your saved content could not load. This page only works through the local server.

  1. Open Terminal
  2. Move into the project folder:
    cd "Varanasi_Guest_House_Final 2"
  3. Start the site:
    node server.js
  4. Then open http://localhost:3000/admin.html

On a Mac you can also just double-click START.command in this folder — it starts the server and opens the browser for you.
